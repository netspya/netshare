## 🚀 Sobre o Projetos

O **NetShare** é uma solução leve e minimalista projetada para quem precisa compartilhar a tela sem complicações. Chega de criar contas, aceitar termos gigantescos ou instalar softwares pesados só para dar uma rápida apresentação ou tirar uma dúvida.

Abra o link, coloque um nome de sua escolha, clique em compartilhar e pronto!

## ✨ Recursos

* **🆓 100% Gratuito:** Sem planos pagos, assinaturas ou limites de uso.
* **⚡ Sem Conta/Zero Friction:** Não exige login, e-mail ou cadastro. Entre e use imediatamente.
* **🔓 Open-Source:** Transparência total. O código é aberto para auditagem e melhorias da comunidade.
* **🔒 Privado & Seguro:** Conexão direta e sem intermediários desnecessários.
